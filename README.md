# Трекер выпитой воды

Приложение для отслеживания количества выпитой воды за день. Позволяет добавлять воду в один клик или вводить своё значение.

## Запуск проекта:
```bash
# Установить зависимости
npm install

# Запустить dev-сервер
npm run dev
```

Приложение откроется на **http://localhost:5173**
